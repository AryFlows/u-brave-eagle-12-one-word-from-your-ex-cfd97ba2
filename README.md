The word an ex would use to describe me: the classic verdict on someone who

## Run

```sh
node main.ts
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 24 characters, not only white
space, and exactly one word. This entry is 11 characters, a single word, no
trailing newline.

## Why this word

Every ex has one word for the person they left, and for a lot of us it is
this one. It needs no backstory: read it once and you already know the whole
relationship — the unanswered texts, the "busy" weekends, the emotional
voicemail that never got returned. Painfully honest, instantly relatable, and
funny precisely because nobody can argue with it.
